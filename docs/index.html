FDE L2 System Guarantees

Core architectural principles implemented in the backend service

1. Strict Idempotency

Two-tier deduplication protecting against network replays (requestId) and business entity duplicates (transactionId). Replayed transactions return cached confirmations without mutating balances.

2. Causal Sequence Resolution

Option A sequence ordering. Premature sequences wait in an atomic account-level holding buffer. When preceding sequences arrive, a cascading drain recursively executes all unblocked records.

3. Transient Fault Resilience

Isolates permanent schema failures from transient network timeouts. Retries transient errors safely within a max retry budget of 3 attempts without double-effect.
